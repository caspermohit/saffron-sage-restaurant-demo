# Restaurant API

Laravel 12, Sanctum authentication and MySQL persistence for the Saffron & Sage restaurant system.

See the [project README](../README.md) for setup, testing, features and limitations. Set your own `STAFF_EMAIL` and `STAFF_PASSWORD` before seeding. Browser demo credentials are not automatically enabled in this backend.

Run `php artisan test` for feature tests. Docker/AWS configuration is documented in [docs/AWS.md](../docs/AWS.md).
